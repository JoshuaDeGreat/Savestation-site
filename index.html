Quick Start

  1. Back up your save (keep an untouched copy somewhere safe).
  2. Import your save (.xml or .xml.gz).
  3. Queue edits, review changes, then Export to a new file.

Tip: Edits are queued in memory and only written when you export. :contentReference[oaicite:0]{index=0}
